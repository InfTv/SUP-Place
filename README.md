# SUP Place

Локальное Android-приложение для учёта проката SUP и каяков. Данные хранятся
на телефоне и не требуют отдельного сервера.

## Возможности

- инвентарь и активные прокаты;
- брони с предоплатой и заметками;
- тарифы и автоматический расчёт стоимости;
- округление времени старта и завершения до пяти минут;
- история и удаление ошибочных записей;
- экспорт, импорт, просмотр и полное восстановление отчётов.
- проверка и установка обновлений через GitHub Releases.

## Сборка

Требуются JDK 17 и Android SDK 35.

```text
gradlew.bat assembleDebug
```

Release-подпись передаётся только через переменные окружения и никогда не
хранится в репозитории:

```text
SUP_PLACE_KEYSTORE
SUP_PLACE_STORE_PASSWORD
SUP_PLACE_KEY_ALIAS
SUP_PLACE_KEY_PASSWORD
```

Постоянный release-сертификат имеет SHA-256 fingerprint
`FC:9C:49:84:61:21:3F:9E:FD:9B:0C:EE:A9:D2:48:98:F3:57:D2:22:45:18:3F:8E:10:B0:3F:02:94:E9:83:CA`.
Ключ менять нельзя: иначе Android не установит следующую версию поверх уже
установленного приложения.

## Совместимость отчётов

Любая новая версия обязана принимать все предыдущие форматы отчётов. Новые
поля добавляются как необязательные, а неизвестные поля сохраняются. Проверка
миграций запускается так:

```text
node tests/report-migration.test.mjs
node tests/rental-rules.test.mjs
node tests/version-manifest.test.mjs
node tests/update-ui.test.mjs
node tests/native-updater-source.test.mjs
node tests/report-restore.test.mjs
```

Подробности восстановления 0.4.8 находятся в
[`docs/recovery-notes.md`](docs/recovery-notes.md).

Порядок публикации следующих APK описан в
[`docs/releasing.md`](docs/releasing.md).

## Стабильность запуска

Нативный startup-path 0.4.16 сохранён от проверенной на устройстве 0.4.15/0.4.10.
Изменения 0.4.16 остаются в WebView UI/данных: после успешного восстановления
полученная копия отчёта удаляется автоматически; при ошибке сохранения копия
остаётся доступной. Нативный updater не менялся перед контрольным тестом обновления.


## Обновление 0.4.17

Исправлено завершение системной загрузки APK: receiver `ACTION_DOWNLOAD_COMPLETE`
регистрируется как system-only без export-флагов, как требует Android 14+. Это
позволяет приложению получить событие DownloadManager, проверить SHA-256 и
автоматически открыть системный установщик. Остальная логика 0.4.16 не менялась.
